# Fábulas Musicais · site das aulas

Landing page publicada em https://fabulasmusicais.com.br pelo GitHub Pages.

- `index.html`: a página inteira.
- `img/`: imagens da marca, personagens e fotos.
- Para colocar o vídeo: crie a pasta `video/` com `apresentacao.mp4` e, no fim do `index.html`, troque `VIDEO.arquivo` por `"video/apresentacao.mp4"` (ou preencha `VIDEO.youtube` com o ID do vídeo).
